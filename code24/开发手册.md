# 基于 Python 的大模型多模态应用开发手册

## 一、项目总览与需求分析

### 1.1 任务背景
随着大语言模型（LLM）和多模态技术的飞速发展，AI 应用已从单一的文本交互扩展到视觉、听觉及视频生成等多个维度。本项目旨在通过阿里云 DashScope（通义千问）平台，系统性地演示如何利用 Python 构建涵盖文本、图像、音频和视频的全栈多模态应用。

### 1.2 需求分析
本项目的核心目标是让开发者掌握以下能力：
1. **模型选型与调用**：了解并调用不同领域的 SOTA（State-of-the-Art）模型。
2. **多模态融合**：实现跨模态的链式调用（如：文生图 -> 图生文）。
3. **工程化实践**：掌握同步/异步调用、流式输出、本地文件处理及错误重试等工程技巧。

### 1.3 教学任务拆分
为了循序渐进地掌握多模态开发，我们将整个学习过程拆分为 **7 个核心模块**：

| 模块 | 主题 | 核心知识点 | 对应代码 |
| :--- | :--- | :--- | :--- |
| **模块一** | **环境搭建与模型探索** | API Key 配置、LangChain 适配、模型列表获取 | `0_list_models.py` |
| **模块二** | **大语言模型对话 (LLM)** | 单轮/多轮对话、流式输出、System Prompt、参数调优 | `1_llm.py` |
| **模块三** | **文生图应用 (T2I)** | 提示词工程、负面提示词、图片尺寸控制、异步下载 | `2_text2image.py` |
| **模块四** | **图生文与视觉理解 (VQA)** | 视觉模型调用、Base64 编码、OCR 识别、多图对比 | `3_image2text.py` |
| **模块五** | **图生视频 (I2V)** | 静态图动态化、视频生成参数、长耗时任务处理 | `4_image2video.py` |
| **模块六** | **语音合成与识别 (TTS/ASR)** | 音色选择、语速音量调节、音频转文字、结果解析 | `5_text2audio.py`, `6_audio2text.py` |
| **模块七** | **多模态综合实战** | 视频内容理解、链式任务设计、图文混合推理 | `7_multimodal_mix.py` |

## 二、项目简介

本项目是 Qwen（通义千问）大模型多模态应用的完整教程，涵盖文本对话、文生图、图生文、图生视频、文生音频（TTS）、音频转文字（STT）以及多模态混合使用等七大核心场景。

所有案例通过阿里云 DashScope API 调用千问系列大模型。大模型对话和视觉理解使用 LangChain 框架的 `ChatOpenAI` 进行调用，文生图/图生视频/TTS/STT 使用 DashScope SDK 调用。

## 七、各功能模块详解

### 7.1 大语言模型调用

使用 LangChain 的 `ChatOpenAI` 调用 Qwen 大模型：

```python
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, SystemMessage, AIMessage

# 创建 LLM 实例
llm = ChatOpenAI(
    model="qwen-plus",
    api_key="your-key",
    base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
    temperature=0.7,
    max_tokens=2000,
)

# 方式1：直接传入字符串（单轮对话）
response = llm.invoke("你好")
print(response.content)

# 方式2：传入消息列表（多轮对话）
messages = [
    SystemMessage(content="你是一个Python专家"),
    HumanMessage(content="解释什么是装饰器"),
]
response = llm.invoke(messages)
print(response.content)

# 方式3：流式输出
for chunk in llm.stream("写一首诗"):
    print(chunk.content, end="", flush=True)

# 获取 Token 用量
usage = response.response_metadata.get("token_usage", {})
```

**关键参数**：
- `temperature`：0~2，控制随机性，越低越确定
- `max_tokens`：最大输出 token 数
- `top_p`：核采样，0~1
- `stream`：是否流式输出

### 7.2 文生图调用

通过 DashScope SDK 的 `ImageSynthesis` API：

```python
from dashscope import ImageSynthesis

result = ImageSynthesis.call(
    model="wan2.2-t2i-flash",
    prompt="一只可爱的猫咪坐在窗台上",
    n=1,            # 生成图片数量
    size="1024*1024",  # 图片尺寸
    steps=4,        # 推理步数（仅 turbo 模型）
)

# 获取图片 URL
image_url = result.output.results[0].url
```

**关键参数**：
- `prompt`：图片描述文本（必填）
- `negative_prompt`：负面提示词
- `n`：生成数量（1~4）
- `size`：支持 "1024*1024", "720*1280", "1280*720" 等

### 7.3 图生文调用

使用 LangChain 的 `ChatOpenAI` 调用 Qwen 视觉模型：

```python
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage
import base64

# 创建视觉 LLM 实例
llm = ChatOpenAI(
    model="qwen-vl-plus",
    api_key="your-key",
    base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
)

# 方式1：通过图片 URL
message = HumanMessage(content=[
    {"type": "image_url", "image_url": {"url": "https://example.com/image.jpg"}},
    {"type": "text", "text": "请描述这张图片"},
])
response = llm.invoke([message])
print(response.content)

# 方式2：通过本地图片 base64
with open("local.jpg", "rb") as f:
    img_b64 = base64.b64encode(f.read()).decode()

message = HumanMessage(content=[
    {"type": "image_url", "image_url": {"url": f"data:image/jpeg;base64,{img_b64}"}},
    {"type": "text", "text": "请描述这张图片"},
])
response = llm.invoke([message])
print(response.content)
```

**支持的图片格式**：JPEG、PNG、WEBP、GIF

**图片输入方式**：
1. Base64 编码（本地文件）
2. 图片 URL（公网可访问）

### 7.4 图生视频调用

通过 DashScope SDK 的 `VideoSynthesis` API：

```python
from dashscope import VideoSynthesis

result = VideoSynthesis.call(
    model="wanx2.1-i2v-turbo",
    prompt="图片中的人物开始跳舞",
    img_url="https://example.com/image.jpg",
    duration=5,     # 视频时长（秒）

video_url = result.output.results[0].url
```

**关键参数**：
- `prompt`：描述期望的视频动态效果
- `img_url`：输入图片 URL
- `duration`：视频时长

### 7.5 语音合成（TTS）调用

通过 DashScope SDK 的 `SpeechSynthesizer` API：

```python
from dashscope.audio.tts_v2 import SpeechSynthesizer, AudioFormat

# 创建合成器实例
synthesizer = SpeechSynthesizer(
    model="cosyvoice-v2",
    voice="longxiaochun_v2",  # 音色
    format=AudioFormat.MP3_24000HZ_MONO_256KBPS,
    volume=50,
    speech_rate=1.0,
)

# 调用合成
audio_data = synthesizer.call("你好，欢迎学习大模型多模态应用")

with open("output.mp3", "wb") as f:
    f.write(audio_data)
```

**常用音色**：
- `longxiaochun_v2`：龙小春（女声）
- `longxiaoxia_v2`：龙小夏（女声）
- `longxiaobai_v2`：龙小白（男声）
- `longlaotie_v2`：龙老铁（男声，东北话）

### 7.6 语音识别（STT）调用

通过 DashScope SDK 的 `Transcription` API：

```python
from dashscope.audio.asr import Transcription

# 异步提交任务
task = Transcription.async_call(
    model="paraformer-v2",
    file_urls=["https://example.com/audio.wav"],
)

# 等待任务完成
result = Transcription.wait(task.output.task_id)

# 获取识别文本
text = result.output.results[0].transcription
```

**支持的音频格式**：WAV、MP3、M4A、OPUS 等

## 八、学习总结与展望

### 8.1 课程回顾
通过这 7 个模块的学习，我们完成了从基础环境配置到复杂多模态应用的完整闭环：
*   **基础扎实**：掌握了 LangChain 与 DashScope SDK 的核心用法。
*   **技能全面**：覆盖了 LLM、CV（计算机视觉）、Audio（语音处理）三大 AI 领域。
*   **实战导向**：每个模块都提供了可直接运行的生产级代码示例。

### 8.2 最佳实践建议
1. **流式体验**：在聊天场景中务必使用 `stream=True` 以降低用户等待焦虑。
2. **异步处理**：对于图生视频、长音频识别等耗时操作，优先采用异步调用并配合进度提示。
3. **成本控制**：根据业务场景选择合适的模型规格（如日常测试使用 `turbo` 或 `flash` 系列）。
4. **安全防护**：对用户输入的文本和图片进行必要的内容审核，防止恶意注入。

### 8.3 未来展望
多模态技术正在重塑人机交互的方式。建议在此基础上进一步探索：
*   **Agent 智能体**：结合 LangGraph 构建能自主规划的多模态 Agent。
*   **RAG 知识库**：将多模态数据（如图片描述、视频字幕）存入向量数据库，实现更精准的知识检索。
*   **端侧部署**：探索轻量化模型在本地设备的运行可能性。
