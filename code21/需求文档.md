# RAG知识库系统需求文档

## 1. 项目概述

### 1.1 项目名称
智能RAG知识库问答系统

### 1.2 项目简介
基于Streamlit框架构建的Web界面RAG（Retrieval-Augmented Generation）知识库系统，支持用户上传文档进行智能问答，集成提示词管理功能，提供临时对话和持久化知识库两种模式。

### 1.3 技术栈
- **编程语言**: Python 3.12
- **Web框架**: Streamlit
- **AI框架**: LangChain 1.0+
- **向量数据库**: ChromaDB / FAISS
- **大语言模型**: 通义千问(Qwen)系列
- **嵌入模型**: Qwen Embedding
- **环境管理**: python-dotenv

### 3.3 数据流设计

#### 3.3.1 临时文档问答流程
```
用户上传文档 → 文档解析 → 文本分割 → 向量化 
    → 临时向量存储 → 用户提问 → 检索相关片段 
    → LLM生成回答 → 显示结果 → 会话结束清理
```

#### 3.3.2 持久化知识库流程
```
上传文档 → 文档解析 → 文本分割 → 向量化 
    → 存入ChromaDB → 索引建立 → 用户提问 
    → 检索知识库 → LLM生成回答 → 显示结果
    → 保留数据供后续使用
```
#### 3.3.3 持久化说明

- 1、不需要存储业务流数据，只需要存储知识库数据。
- 2、即只做知识库、文档的向量数据库存储，无需关系数据库存储其他信息。
- 3、如有需要可使用文件流（json）存储部分关键数据替代sqlite，不要使用sqlite、mysql等关系数据库。
- 4、非必要，可不使用sqlite、mysql、postgresql等数据库。
