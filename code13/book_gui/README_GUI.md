# 图书管理系统（GUI 窗体应用版）

## 项目简介
这是一个使用 Python tkinter 库开发的图形界面图书管理系统，适合 Python 初学者学习面向对象编程和 GUI 开发。

## 项目结构
```
book_gui/
├── book.py          # Book 类定义 - 图书模型
├── library.py       # Library 类定义 - 图书馆管理
├── main_gui.py      # GUI 主界面 - 图形用户界面
├── run.py           # 启动脚本 - 运行此文件启动程序
└── README.md        # 项目说明文档
```

## 功能特点

### 1. 图书管理功能
- ✅ 添加新书：录入书名、作者、ISBN 信息
- ✅ 查看所有图书：以表格形式展示全部图书
- ✅ 搜索图书：根据书名或作者进行模糊搜索

### 2. 借阅管理功能
- ✅ 借书操作：将指定 ISBN 的图书状态改为"已借出"
- ✅ 还书操作：将指定 ISBN 的图书状态改为"可借阅"
- ✅ 查看已借出图书：筛选显示所有被借出的图书

### 3. 界面特性
- 📊 左右分栏布局：左侧操作区，右侧显示区
- 📋 树形视图表格：清晰展示图书信息
- 📈 实时状态统计：显示总图书数、可借阅数、已借出数
- ⚠️ 消息提示框：提供操作反馈和错误提示

## 运行方法

### 方法一：使用启动脚本（推荐）
```bash
python run.py
```

### 方法二：直接运行主程序
```bash

```

## 使用说明

### 1. 添加图书
1. 在左侧"添加图书"区域输入书名、作者、ISBN
2. 点击"添加图书"按钮
3. 系统会自动检查 ISBN 是否重复
4. 添加成功后会在右侧显示新图书

### 2. 搜索图书
1. 在"搜索图书"区域输入关键词（书名或作者）
2. 点击"搜索"按钮
3. 右侧会显示匹配的图书列表
4. 点击"显示全部"可恢复显示所有图书

### 3. 借书操作
1. 在"借阅管理"区域输入要借阅的图书 ISBN
2. 点击"借书"按钮
3. 系统会检查图书是否存在以及是否可借
4. 成功后图书状态会变为"已借出"

### 4. 还书操作
1. 在"借阅管理"区域输入要归还的图书 ISBN
2. 点击"还书"按钮
3. 系统会检查图书是否存在以及是否已借出
4. 成功后图书状态会变为"可借阅"

### 5. 查看分类
- 点击"查看所有图书"：显示图书馆所有藏书
- 点击"查看已借出图书"：只显示已被借出的图书

## 技术要点

### 面向对象设计
- **Book 类**：封装图书属性（书名、作者、ISBN、借阅状态）和方法（借书、还书、获取信息）
- **Library 类**：管理图书集合，提供添加、搜索、借阅等功能
- **BookManagerGUI 类**：实现图形用户界面的所有交互逻辑

### 模块化结构
- 三个独立的模块文件，职责清晰
- main_gui.py 导入 book 和 library 模块
- 符合高内聚低耦合的设计原则

### GUI 组件应用
- `tk.Tk`：主窗口
- `ttk.Frame`：框架容器
- `ttk.Label`：标签显示
- `ttk.Entry`：单行输入框
- `ttk.Button`：按钮控件
- `ttk.Treeview`：树形视图（表格）
- `ttk.Scrollbar`：滚动条
- `messagebox`：消息对话框

## 常见问题

### Q1: 为什么运行时报错"ModuleNotFoundError: No module named 'book'"?
**A:** 确保所有 `.py` 文件在同一目录下，并且从该目录运行程序。

### Q2: 输入中文显示乱码怎么办？
**A:** 这是正常的，tkinter 支持中文显示。如果遇到编码问题，请确保文件使用 UTF-8 编码保存。

### Q3: 如何关闭程序？
**A:** 点击窗口右上角的关闭按钮即可退出程序。

### Q4: 数据会保存吗？
**A:** 当前版本是内存存储，关闭程序后数据会丢失。可以通过扩展功能实现数据持久化。
