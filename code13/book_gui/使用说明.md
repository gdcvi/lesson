# 快速开始指南

## 🚀 启动程序

### 方法一：双击启动（最简单）
直接双击 **`启动.bat`** 文件即可运行程序。

### 方法二：命令行启动
1. 打开命令行工具（CMD 或 PowerShell）
2. 进入 `book_gui` 文件夹
3. 运行命令：
   ```bash
   python run.py
   ```
   或
   ```bash
   python main_gui.py
   ```

## 📋 功能操作指引

### 1️⃣ 添加图书
- 在左侧【添加图书】区域输入：
  - 书名（必填）
  - 作者（必填）
  - ISBN（必填，不能重复）
- 点击"添加图书"按钮
- ✅ 成功提示后会显示在右侧列表中

### 2️⃣ 搜索图书
- 在【搜索图书】区域输入关键词
- 可以是书名或作者的任何部分
- 点击"搜索"按钮
- 点击"显示全部"恢复完整列表

### 3️⃣ 借书操作
- 在【借阅管理】输入要借的图书 ISBN
- 点击"借书"按钮
- ✅ 成功后图书状态变为"已借出"

### 4️⃣ 还书操作
- 在【借阅管理】输入要还的图书 ISBN
- 点击"还书"按钮
- ✅ 成功后图书状态变为"可借阅"

### 5️⃣ 查看分类
- 【查看所有图书】：显示全部藏书
- 【查看已借出图书】：只看借出的书

## 💡 使用技巧

1. **ISBN 格式建议**：使用 10 位或 13 位数字，如：9787302425465
2. **搜索技巧**：支持模糊搜索，输入部分书名或作者即可
3. **批量操作**：可以连续添加多本图书后再统一借阅
4. **状态查看**：底部状态栏实时显示图书统计信息

## ⚠️ 注意事项

1. **ISBN 唯一性**：同一 ISBN 不能添加两次
2. **借阅规则**：只能借阅"可借阅"状态的书
3. **归还规则**：只能归还"已借出"状态的书
4. **数据保存**：当前版本为内存存储，关闭程序后数据会清空

## 🆘 常见问题

**Q: 程序无法启动？**
A: 确保已安装 Python 3.6+ 版本

**Q: 中文显示异常？**
A: 这是正常显示的，tkinter 完全支持中文

**Q: 如何退出程序？**
A: 点击窗口右上角的 X 关闭按钮

## 📞 技术支持

如遇问题，请检查：
1. Python 版本是否 >= 3.6
2. 所有 .py 文件是否在同一目录
3. 是否正确安装了 tkinter（Python 自带）
