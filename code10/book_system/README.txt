图书管理系统说明文档
===================

项目名称：简易图书管理系统
适合对象：Python初学者

功能说明：
1. 添加图书 - 可以添加新书，包括书名、作者、ISBN
2. 查看所有图书 - 显示图书馆中的所有图书及其借阅状态
3. 搜索图书 - 根据书名或作者搜索图书
4. 借阅图书 - 将指定ISBN的图书标记为已借出
5. 归还图书 - 将指定ISBN的图书标记为可借阅
6. 查看已借出图书 - 显示所有已借出的图书

运行方法：
1. 确保在同一目录下有以下三个文件：
   - book.py (图书类定义)
   - library.py (图书馆类定义)
   - main.py (主程序)
2. 在命令行中运行：python main.py
3. 按照菜单提示进行操作

技术特点：
- 模块化设计：分为book、library、main三个模块
- 面向对象编程：使用Book和Library两个类
- 封装性：类的属性和方法合理封装
- 易于扩展：代码结构清晰，便于后续功能扩展
- 装饰器应用：为关键操作添加日志记录功能
- 文件存储：自动将图书数据保存到books.json文件中，支持数据持久化
