
# Python图书管理系统

## 一、项目概述
**项目名称**：简易图书管理系统  
**适用对象**：Python初学者  
**预计完成时间**：1-2节课  
**学习目标**：掌握模块化设计、**面向对象**编程思想以及基础的Python语法应用

## 二、项目功能需求

### 2.1 核心功能
1. **图书管理功能**
   - 添加新书：能够录入图书信息（书名、作者、ISBN）
   - 查看所有图书：显示图书馆中的全部图书
   - 搜索图书：可以根据书名或作者进行模糊搜索

2. **借阅管理功能**
   - 借书：将指定图书的状态改为"已借出"
   - 还书：将指定图书的状态改为"可借阅"
   - 查看已借出图书：显示所有被借出的图书

3. **用户交互界面**
   - 提供菜单式操作界面
   - 支持用户选择不同功能
   - 提供清晰的操作提示

### 2.2 具体操作流程示例
```
=== 图书管理系统 ===
1. 添加图书
2. 查看所有图书
3. 搜索图书
4. 借阅图书

6. 查看已借出图书
0. 退出系统
====================
请选择操作：1
请输入书名：Python编程入门
请输入作者：张三
请输入ISBN：12345
图书 'Python编程入门' 添加成功！

请选择操作：2
所有图书：
1. Python编程入门 - 张三 (ISBN:12345) [可借阅]
2. 算法导论 - 李四 (ISBN:67890) [已借出]
```

## 七、提示和技巧

1. **如何存储多本图书？**  
   使用列表存储多个Book对象：`self.books = []`

2. **如何查找图书？**  
   遍历图书列表，比较ISBN或关键词

3. **如何标记借出状态？**  
   在Book类中添加is_borrowed属性

4. **如何处理用户输入？**  
   使用input()函数获取用户输入，使用strip()去除空格

5. **如何实现搜索功能？**  
   使用in操作符和lower()方法实现模糊匹配

## 八、常见错误及解决方案

1. **ImportError错误**  
   确保文件名拼写正确，所有文件在同一目录下

2. **属性访问错误**  
   确保在使用对象属性前已正确初始化

3. **循环逻辑错误**  
   检查while循环的终止条件

4. **字符串比较错误**  
   注意大小写敏感问题，使用lower()统一转换
